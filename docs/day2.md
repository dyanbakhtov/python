📝 День 2: Day2

День 2 — Продвинутые типы банковских счетов

🎯 Цель дня
Реализовать несколько дочерних классов счетов с расширенными возможностями.

📋 Требования

1. Наследование
Создать классы:
- SavingsAccount
- PremiumAccount
- InvestmentAccount

2. Функционал SavingsAccount
- 🔒 min_balance — минимальный остаток
- 📈 месячная ставка доходности
- 💰 метод apply_monthly_interest()

3. Функционал PremiumAccount
- ⬆️ увеличенные лимиты
- 💳 возможность овердрафта
- 📊 фиксированная комиссия

4. Функционал InvestmentAccount
- 📊 инвестиционный портфель хранит сумму, распределённую между типами активов
- 💼 допустимые виртуальные типы активов: stocks, bonds, etf
- 📈 метод project_yearly_growth(growth_rates) рассчитывает ожидаемый годовой прирост портфеля
- 🧮 growth_rates передаётся в метод как словарь «тип актива → годовая ставка»
- 🧪 для демонстрации использовать условные ставки: stocks — 10%, bonds — 4%, etf — 7%
- ✅ проверять допустимость типа актива, положительность суммы и достаточность средств

Важно:
- Это упрощённая учебная модель для практики ООП.
- Не нужно выбирать реальные ценные бумаги, искать инвестиционные правила или получать котировки.
- Внешние API и база данных для этого задания не требуются; данные можно хранить в памяти приложения.

5. Полиморфизм
Каждый тип должен переопределять:
- withdraw()
- get_account_info()
- __str__()

6. Тестирование
Создать несколько счетов каждого типа и выполнить различные операции.
